ResearchPulse Windows 单机试用版

1. 把安装包完整解压到有写入权限的位置，例如文档目录或数据盘。
2. 双击「启动研究台.cmd」。浏览器会打开只在本机运行的研究台。
3. 按页面说明接通至少一种模型。SOL 使用本机登录的 Codex，DeepSeek 使用自己的 API Key。
4. 使用飞书日报时，按研究台的授权指引完成飞书应用配置。也可以导入本地日报。
5. 需要完整的论文全文深读时，联网运行「安装论文深读组件.cmd」。CPU 依赖和公开模型
   首次下载量预计超过 3 GB，请预留约 10 GB 空间。完成后重启研究台。
6. 如需每日检查，双击「配置每日检查.cmd」并选择启用，然后在对应项目开启每日检测。
   检查按北京时间 05:00 安排，使用当前 Windows 用户身份。用户登录 Windows 后才可运行。
   移动解压目录后，应在新位置重新运行「配置每日检查.cmd」。

项目和历史记录默认保存在解压目录的 data 文件夹。
可在完全退出研究台后备份该目录。升级时把新版解压到新目录并从新版启动。
已有记录可以在本机查看。飞书同步、在线检索和模型推理需要网络。
