ResearchPulse Windows 单机试用版

1. 把 ZIP 完整解压到 Windows 电脑的文档目录或数据盘，然后双击「ResearchPulse.exe」。
   默认浏览器会打开本机工作台。可为 EXE 创建桌面快捷方式。
2. 在右上角「模型设置」接通至少一种模型。Codex 用户先按链接安装 Codex CLI，然后点击
   「登录 Codex」，在 OpenAI 打开的浏览器页面完成登录。回到研究台刷新模型列表，选择账号
   可用的模型与推理强度，或保留 Codex 默认模型。DeepSeek 使用自己的 API Key。
3. 使用飞书日报时，按研究台的授权指引完成飞书应用配置。也可以导入本地日报。
4. 首次使用论文检索和深读前，联网双击「安装 BGE-M3.cmd」，下载约 2.3 GB 的 BGE-M3
   检索权重。下载完成后重启研究台。Docling、CPU 运行库和文档解析模型已经包含在 ZIP 内。
5. 如需每天检查日报，双击「配置每日检查.cmd」并选择启用，在对应项目开启每日检测。
   检查按北京时间 05:00 安排，使用当前登录的 Windows 用户身份。移动解压目录后，
   应在新位置重新配置每日检查。

解压到哪里就在哪里运行。项目、历史记录和下载的检索权重保存在解压目录的 data 文件夹。
完全退出后，可以将整个解压目录移动到同一台电脑的其他位置。升级时把旧版的 data 复制到新版目录。
模型密钥和飞书授权由当前 Windows 用户保护，换电脑或 Windows 用户后需要重新配置。
已有记录可以在本机查看。飞书同步、在线检索和模型推理需要网络。
